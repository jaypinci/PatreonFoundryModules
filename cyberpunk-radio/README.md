# Cyberpunk Radio

A Foundry VTT (v13+) module that turns your world's Playlists into an in-fiction radio — tunable channels, custom station branding, and a floating player your table can interact with.

Made by [FailingUp](https://www.patreon.com/FailingUp).

## Features

- **Channels linked to Playlists** — map any number of channels to existing Foundry Playlists.
- **Full station branding** — name, frequency, logo/emoji, tagline, description, background image, and background/accent colors per channel.
- **Two built-in themes** — Cyberpunk (neon/CRT) and Fantasy (parchment/candlelight), switchable per-client.
- **Player controls** — play/pause, skip, volume, and channel switching, with a GM-configurable toggle for how much control players get.
- **Multiplayer-safe** — players trigger playback via a socket relay to the GM; only the GM ever writes world settings.
- **Multiple access points** — scene control button, Playlists sidebar button, and player-list button.

## Installation

1. In Foundry's **Add-on Modules** tab, click **Install Module**.
2. Paste the manifest URL: `<manifest URL goes here once hosted>`
3. Enable **Cyberpunk Radio** in your world's module settings.

## Usage

- Click the radio icon in the scene controls, the Playlists sidebar, or the player list to open the radio.
- As GM, click **Configure Channels** (gear icon in the radio window) to add/edit/remove channels and link them to Playlists.
- Use the theme toggle button in the radio window to switch between Cyberpunk and Fantasy styling (this is a per-client preference).
- Use the **Allow Player Control** and **Show Radio Button in Player List** settings (Module Settings) to control what players can do.

## Compatibility

- Foundry VTT v13.
